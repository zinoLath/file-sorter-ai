# Triage Labels

As skills falam em cinco papéis canônicos de triage. Este arquivo mapeia os papéis para os labels usados no tracker deste repo.

| Label em mattpocock/skills | Label no nosso tracker | Significado                                  |
| -------------------------- | ---------------------- | -------------------------------------------- |
| `needs-triage`             | `needs-triage`         | Mantenedor precisa avaliar a issue           |
| `needs-info`               | `needs-info`           | Aguardando mais informação do relator        |
| `ready-for-agent`          | `ready-for-agent`      | Totalmente especificada, pronta para agente  |
| `ready-for-human`          | `ready-for-human`      | Requer implementação humana                  |
| `wontfix`                  | `wontfix`              | Não será tratada                             |

Quando uma skill mencionar um papel, use o label correspondente desta tabela.
